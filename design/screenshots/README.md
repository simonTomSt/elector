# Zrzuty ekranów makiet – Symulator szafy sterowniczej

Rozdzielczość: 1440 px szerokości przy skali 2× (pliki 2880 px). Ekrany o większej wysokości zapisane w całości.
Font na zrzutach: Inter jako zamiennik fontu systemowego (San Francisco / Segoe UI) – w przeglądarce użytkownika wygląd tekstu będzie nieco inny.

Wrzuć ten folder do repo jako `design/screenshots/`.
